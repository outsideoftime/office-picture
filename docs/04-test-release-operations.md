# OfficePicture 测试、发布与运维文档

## 1. 质量目标

OfficePicture 运行在 Word、PowerPoint、Excel 进程内。质量底线不是“功能失败时给出丰富错误页”，而是“任何失败都不拖垮宿主、不破坏文档、不意外覆盖用户数据”。

### 发布阻断条件

- 任一支持宿主无法加载插件或无法预览基本图片。
- 预览导致 Office 崩溃、挂死、文档修改或选择内容丢失。
- 一次双击产生两个及以上预览。
- 预览无法通过可见按钮或 `Esc` 关闭。
- 正式包未签名、签名无效、三个安装包版本不一致。
- 常规文本/图片剪贴板在预览后稳定丢失或被错误替换。

## 2. 测试策略

| 层级 | 目标 | 执行方式 | 频率 |
|---|---|---|---|
| 静态检查 | 编译、引用、Nullable、资源释放模式 | MSBuild + 代码审查 | 每次提交 |
| Core 单元测试（规划） | 缩放、Fit、Clamp、状态转换 | 测试项目，逻辑纯函数化 | 每次提交 |
| 宿主集成 | 事件、选区、图片复制、父窗口 | Word/PPT/Excel 样本文档 | 每个候选版本 |
| UI/可用性 | 工具条、键盘、滚动、多屏/DPI | 手工 + Windows UI Automation | 每个候选版本 |
| 安装升级 | 首装、升级、修复、卸载、证书 | 干净虚拟机 | 每次发布 |
| 稳定性 | 连续预览、资源泄漏、大图 | 长稳脚本 + Process Explorer/PerfMon | 重大版本 |

## 3. 测试环境矩阵

正式支持范围尚待产品确认。建议最小矩阵如下：

| 维度 | 基线 | 扩展 |
|---|---|---|
| Windows | Windows 11 64 位 | Windows 10 22H2（若仍在支持范围） |
| Office | Office 2021 64 位 | Microsoft 365 32/64 位、Office 2019 |
| 显示 | 1920×1080 / 100% | 125%、150%、200%、双屏异 DPI |
| 权限 | 标准用户 | 企业策略、无管理员权限、受保护视图 |
| 主题 | 默认浅色 Office + 深色预览 | Office 深色、Windows 高对比度 |
| 安装 | 干净环境 | 旧版覆盖、修复、卸载重装 |

每个环境记录：Windows build、Office 完整版本/位数、VSTO Runtime、.NET Framework、插件版本、证书发布者。

## 4. 测试数据

为三宿主分别维护等价样本文档，至少包含：

- 640×480 JPEG、透明 PNG、1×1 小图、超宽图、超高图。
- 1920×1080、4K、建议上限附近的大图。
- 嵌入图片、链接图片、Word 浮动图片。
- 裁剪/旋转/带透明度/压缩后的 Office 图片。
- 普通文本、文本框、矩形、组合对象、图表、OLE、SmartArt。
- 多选对象和分组内图片。
- 只读、兼容模式、受保护视图文档（验证安全边界，不要求绕过限制）。

样本文档不得包含真实敏感数据；使用合成图片并固定校验基线。

## 5. 核心功能用例

### TC-001 Word 嵌入图片预览

**前置**：Word 插件已加载，文档含嵌入式图片。  
**步骤**：单击图片；双击。  
**期望**：仅打开一个“图片预览 · Word”窗口；图片完整可见；Office 文档未修改。  
**覆盖**：FR-001、FR-002、FR-003、FR-004、FR-006、FR-007。

### TC-002 Word 浮动/链接图片预览

分别对浮动图片、链接图片重复 TC-001。期望均能打开；对断链图片记录 Office Copy 行为，失败时不得崩溃。

### TC-003 PowerPoint 图片预览

选中普通图片与链接图片分别双击。期望显示 PowerPoint 宿主名；非图片 Shape 不打开预览且保留 PowerPoint 默认行为。

### TC-004 Excel 图片 Shape 预览

选中工作表图片 Shape 并双击。期望 Hook 只在 Excel 文档窗口内触发；单元格双击不打开预览并保留 Excel 编辑行为。

### TC-005 不支持对象

对文本、图表、OLE、组合对象、普通 Shape 执行双击。期望无预览；宿主仍可执行原双击行为；无异常窗口和日志洪泛。

### TC-006 首次适应窗口

对横图、竖图、小图、大图打开预览。期望图片等比完整可见、四周有边距；当前比例与计算值一致并处于 10%～800%。

### TC-007 100%

打开大图后点击“100%”。期望比例为 100%；渲染尺寸等于原图像素尺寸；超过视口时出现滚动访问能力。

### TC-008 按钮缩放

连续点击“＋”与“－”。期望每次约 ×1.2 或 ÷1.2；显示百分比同步；最高停在 800%，最低停在 10%。

### TC-009 滚轮缩放

鼠标位于窗体、视口、图片上分别滚轮。期望三处均响应；向上约 ×1.15，向下约 ÷1.15；不越界。

### TC-010 键盘与关闭

验证 `+`、`-`、`Esc`；再次打开后点击“关闭 ✕”。期望键盘缩放正确，两种关闭路径均释放窗口并返回宿主。

### TC-011 Fit/Manual Resize

Fit 模式改变预览尺寸，图片应重新适配。切换 100% 后改变尺寸，比例应保持。再次点击适应窗口，恢复自动跟随。

### TC-012 双击去重

快速双击打开并立即 Esc；在 400 ms 内制造残留/再次双击；之后再正常双击。期望前一阶段无重复窗口，超过去重期可再次打开。

### TC-013 剪贴板文本保护

预先复制包含中文、格式和换行的文本；预览图片；粘贴到安全测试编辑器。期望常见文本内容与格式保持。记录不可恢复格式但不得崩溃。

### TC-014 剪贴板图片/文件列表保护

分别以图片、文件列表为原剪贴板内容执行预览。期望尽可能恢复；若格式无法快照，结果需符合已知限制且无宿主异常。

### TC-015 剪贴板竞争

用测试程序短暂占用剪贴板，或在捕获期间由另一程序写入。期望插件失败可控、Office 可继续使用。此用例用于验证 P1 的重试与序列号方案。

### TC-016 资源长稳

同一宿主连续打开/缩放/关闭 500 次。期望 GDI Handle、User Handle、Private Bytes 无持续线性增长；Office 可继续编辑和保存。

### TC-017 多窗口与多屏

同一宿主打开两个窗口并分布在不同屏幕。分别触发预览。期望预览覆盖正确 Owner，不跑到另一屏；关闭后焦点回到对应文档。

### TC-018 高 DPI 与窄窗口

在 100%、150%、200%、250% 与最小宿主窗口测试。期望工具条可用，关闭不被裁切，图片不变形，文本可读。

### TC-019 宿主关闭与卸载

正常关闭三宿主；Excel 特别检查 Hook 释放。卸载后启动 Office，期望不加载插件、不残留错误对话框。

### TC-020 捕获失败

制造选区瞬态变化、断链或剪贴板不可用。期望不出现空窗、不崩溃、文档可继续操作；若启用 P1 日志，仅记录去敏技术信息。

## 6. 兼容与回归清单

| 类别 | 检查项 |
|---|---|
| 文档完整性 | 打开预览前后文档脏标记、对象位置、尺寸、裁剪、选择状态 |
| Office 默认行为 | 非图片双击、单元格编辑、文本选词、Shape 编辑 |
| 窗口关系 | 模态、Owner、Alt+Tab、任务栏、最小化/还原、焦点 |
| 图片视觉 | 宽高比、透明背景、色彩、裁剪后显示结果、像素比例 |
| 输入 | 按钮、滚轮、主键盘/小键盘 +/-、Esc、Tab（P1） |
| 资源 | 图片 Dispose、Hook 卸载、事件取消订阅、GDI/User Handle |
| 安全 | 受保护视图、宏/插件策略、未受信证书、标准用户安装 |

## 7. 缺陷分级

| 等级 | 定义 | 示例 |
|---|---|---|
| P0 | 数据损失、安全问题、宿主崩溃、无法退出 | 文档被修改；剪贴板稳定被覆盖；Office 崩溃 |
| P1 | 核心任务失败或主要兼容环境不可用 | Excel 图片无法预览；一次双击重复弹窗 |
| P2 | 有替代路径的交互/视觉问题 | 150% DPI 下尺寸文案进入溢出 |
| P3 | 轻微一致性或文案问题 | 间距偏差、不影响理解的标签问题 |

发布要求：P0/P1 为 0；P2 有明确接受人、规避方式和修复版本。

## 8. 发布流程

### 8.1 发布前

- [ ] 确认 Git 工作区仅包含本次发布内容，用户本地证书不入库。
- [ ] 更新四段式版本号和发布说明。
- [ ] 使用受信任的正式代码签名证书；验证有效期与时间戳策略。
- [ ] 三个 Add-in 项目均启用 ClickOnce 清单签名并指向可用证书；只配置 Word 项目会导致 PowerPoint/Excel 在 VSTO 构建目标阶段失败。

### 8.4 灰度与正式发布

1. 内部开发机验证。
2. 3～5 名真实用户、至少两种 Office 环境灰度。
3. 观察 2～5 个工作日，收集匿名技术问题与人工反馈。
4. 无阻断问题后扩大分发。

产品目前无自动更新后台，应明确更新包来源，避免用户从非可信渠道安装。

## 9. 安装、升级、卸载验收

### 首装

- 标准用户按说明安装成功。
- Word、PowerPoint、Excel 的 COM Add-in 列表可见且已启用。
- 第一次启动无证书警告（正式受信环境）。

### 升级

- 高版本覆盖低版本，三个宿主版本一致。
- 升级不要求手工清理旧程序集或注册表残留。
- 打开的 Office 进程需先关闭，提示清晰。

### 卸载

- 从 Windows 已安装应用或 ClickOnce 管理入口完成卸载。
- 三宿主不再加载插件；无残留任务栏项、Hook 或启动错误。
- 用户文档与 Office 设置不被删除。

### 回滚

- 保留上一个已验证版本及哈希。
- 发现 P0/P1 后停止分发，卸载问题版本，再安装上一个受信版本。
- 若证书泄露，立即停止使用相关证书并重新签名发布；不能仅回滚二进制。

## 10. 运行支持与诊断

### 一线排查顺序

1. 确认 Windows、Office 版本和位数。
2. 确认对应宿主插件已安装并在“COM 加载项”中启用。
3. 确认 VSTO Runtime 和 .NET Framework 4.7.2 可用。
4. 使用标准样本文档与普通嵌入图片复现。
5. 检查是否处于受保护视图、企业禁用插件策略或剪贴板限制环境。
6. 记录插件版本、复现时间、宿主，不要求用户提供敏感文档；优先用脱敏样本复现。

### 常见问题

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 双击无反应 | 对象不支持、插件未加载、捕获失败 | 用嵌入式图片验证；检查加载项状态 |
| Excel 单元格双击无预览 | 正常行为 | 插件只处理图片 Shape |
| 安装提示发布者不受信 | 测试证书或证书链问题 | 使用组织信任的正式证书重新发布 |
| 大图打开缓慢 | Office Copy/位图克隆内存开销 | 使用较小样本确认；P1 引入大图保护 |
| 剪贴板内容变化 | 自定义格式或并发写入 | 记录格式/复现步骤，不收集实际内容 |
| 预览位置异常 | 多屏/DPI/Owner 句柄问题 | 记录显示布局和缩放，切回单屏验证 |
