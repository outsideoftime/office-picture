## 产品一句话

OfficePicture 是 Word、PowerPoint、Excel 桌面版的原生 VSTO 图片预览插件：用户选中已插入的图片并双击，即可在当前 Office 窗口上方沉浸式查看大图，无需知道图片路径或离开文档。

## 当前版本快照

- 平台：Windows + Microsoft Office 桌面版。
- 宿主：Word、PowerPoint、Excel。
- 核心任务：选中图片 → 双击 → 查看 → 缩放 → 关闭 → 返回原工作上下文。
- 支持：嵌入/链接图片，以及 Office 中若干图片 Shape 类型。
- 不支持：图表、OLE、组合对象、非图片 Shape、多图浏览、编辑、导出、批注。
- 技术：.NET Framework 4.7.2、C#、VSTO、WinForms、Office Interop、ClickOnce。
- 发布：三个宿主分别安装；仓库已有统一版本号的离线发布脚本。

## 倒推口径

1. **事实优先**：以源代码、项目配置、发布脚本和 README 为事实来源。
2. **现状/规划分离**：未实现能力统一标记为“规划”，避免把建议误当成现有功能。
3. **可验收**：每项 P0 需求都有可观察的验收结果，并在测试文档中落到用例。
4. **可迁移**：结构可作为其他桌面插件、轻量工具或单任务产品的文档模板。
